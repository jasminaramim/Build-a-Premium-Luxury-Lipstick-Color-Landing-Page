## ✨ Key Features

- **Cinematic Hero Video Scrubbing (`heroone.mp4`)**:
  - Precision scroll-scrubbed video engine powered by a smooth `requestAnimationFrame` interpolation loop and GSAP `ScrollTrigger`.
  - Minimal editorial typography that gracefully dissolves as you scroll, giving way to full-screen video brilliance.

- **Bidirectional Scroll Cinema (`videohero.mp4`)**:
  - Forward and reverse video scrubbing synchronized with page scroll depth, positioned right below the formulation science lab.
  - Interactive playback controls: manual reel, audio toggle, and full-screen theater mode.

- **16 Curated Lip Shades & Architectural Bullet**:
  - Interactive swatch palette featuring Reds, Nudes, Pinks, and Bolds.
  - Three distinct couture finishes: *Velvet Matte*, *Satin Cream*, and *Lacquer Gloss*.
  - Real-time 3D lipstick tube viewer with dynamic lighting reflections.

- **Sensory Lubricant Slip & Gloss Simulation**:
  - Interactive tactile slider dynamically adjusting specular reflection, impasto smear viscosity, and liquid micro-droplet shine.

- **AI-Inspired Complexion & Undertone Finder**:
  - Multi-step shade matching algorithm evaluating skin undertones (Cool, Neutral, Warm) and desired mood (Natural, Classic, Bold, Glamour).

- **Complimentary Laser Monogramming Studio**:
  - Real-time monogram laser-etching preview directly onto the fluted 24K gold collar.

- **Luxury Cart Drawer & Parisian Salon Ambient Sound**:
  - Sliding side-cart with dynamic item management and Web Audio API ambient salon chord generator.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/jasminaramim/Build-a-Premium-Luxury-Lipstick-Color-Landing-Page.git
cd Build-a-Premium-Luxury-Lipstick-Color-Landing-Page
```

### 2. Install Dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Launch Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

### 4. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Push your repository to GitHub.
2. Visit [Vercel](https://vercel.com/) and click **Add New Project**.
3. Import `Build-a-Premium-Luxury-Lipstick-Color-Landing-Page`.
4. Set Framework Preset: **Vite**.
5. Click **Deploy**.
